## Что делает это приложение

Загрузите КТ-снимок брюшной полости (PNG/JPG или **DICOM .dcm**). Кликните на изображение для установки точек промпта. Получите мгновенные маски сегментации с:

- Коэффициент сходства Dice (Dice Similarity Coefficient)
- Оценка IoU (Intersection over Union)
- Разбор по органам
- Визуализация тепловой карты внимания SAM2
- Поддержка многоточечного промптинга
- Измерение задержки в реальном времени
- **Экспорт результатов**: маска как PNG (чёрный фон, цветные области маски без подписей — удобно для постобработки) и полный отчёт по метрикам в **JSON** или **CSV**
- **Восстановление сессии из JSON-отчёта**: загрузите ранее сохранённый отчёт — точки промпта, геометрия масок, метрики, оценки по органам и окно W/L будут восстановлены; если тот же снимок ещё открыт, маски лягут точно на место
- **Поддержка DICOM (.dcm)**: собственный парсер на чистом JS — читает несжатые файлы (Explicit/Implicit VR Little Endian), пересчитывает пиксели в единицы Хаунсфилда (Rescale Slope/Intercept) и показывает метаданные (пациент, исследование, модальность, дата, диапазон HU)
- **Настройка окна W/L (Window/Level)**: слайдеры ширины и центра окна + быстрые пресеты (брюшная полость, мягкие ткани, лёгкие, кости, поджелудочная, печень, мозг); по умолчанию берутся значения из тегов WindowWidth/WindowCenter файла
- **W/L мышью прямо на снимке**: перетаскивание — по горизонтали ширина окна, по вертикали уровень (классическое радиологическое управление); колесо меняет уровень, Shift+колесо — ширину; под курсором живо показываются координаты и значение HU; обычный клик по-прежнему ставит точку промпта
- **Зум и панорама снимка**: Ctrl+колесо — зум к позиции курсора (0.5×–12×), средняя кнопка — панорамирование, двойной клик или клик по бейджу масштаба — сброс; отсчёт W/L и значение HU под курсором остаются точными на любом масштабе, точки промпта ставятся туда, куда кликнули
- **ROI-замеры**: кнопка «ROI-замеры» — протяните эллипс по снимку и получите эквивалентный диаметр и площадь в мм (из PixelSpacing файла), среднее/min/max HU внутри области; для снимков без PixelSpacing и обычных изображений размеры даются в пикселях; замеры рисуются на отдельном слое и переживают зум, панораму и переключение видов
- **Навигация по DICOM-серии**: выберите или перетащите несколько файлов .dcm — они группируются по SeriesInstanceUID и сортируются по InstanceNumber; слайдер, кнопки ◀/▶ и клавиши ←/→ (Home/End — к краям) листают снимки, при этом окно W/L, зум, точки промпта и ROI-замеры сохраняются

## Поддерживаемая модальность

| Модальность | Органы/Структуры |

| 🩻 **КТ брюшной полости** | Печень, Почка слева, Почка справа, Селезенка, **Поджелудочная железа** |

## Конвейер SAM2

```
Медицинское изображение
      │
      ▼
┌─────────────────┐
│  Hiera Encoder  │  Изображение → 256-мерные признаки патчей
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Prompt Encoder  │  Точки клика → разреженные эмбеддинги
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Mask Decoder   │  Двустороннее трансформерное внимание
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Multi-Scale    │  FPN → маска высокого разрешения
│  Fusion (FPN)   │
└────────┬────────┘
         │
         ▼
  Маска + Dice + IoU
```
